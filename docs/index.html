Ork Documentation

A Go package for SSH-based server automation. Think Ansible, but written in Go.

Define Nodes, Groups, and Inventories

Ork provides a simple, type-safe API for managing remote Linux servers over SSH. Combine Go's strong typing and concurrency with Ansible-style declarative automation — idempotent skills, dry-run mode, and a fluent API.
